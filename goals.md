# Цели на семестр

1. **Docker.** Научиться самостоятельно писать Dockerfile и docker-compose.yml для веб-приложения с базой данных и запускать его на удалённом сервере.
2. **CI/CD.** Настроить конвейер GitHub Actions, который при каждом push запускает проверки и автоматически выполняет деплой на сервер.
3. **Linux.** Уверенно администрировать Ubuntu Server через SSH: пользователи и sudo, systemd, ufw, журналы, базовая диагностика сети.
