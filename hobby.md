# Мой пет-проект

Идея: Telegram-бот для учёта личных расходов — пользователь пишет «кофе 250», бот сохраняет трату и по команде /report присылает сводку за неделю или месяц.
Стек: Python (aiogram), PostgreSQL, Docker
Цель: научиться упаковывать приложение в контейнер и настроить его автоматический деплой через GitHub Actions
