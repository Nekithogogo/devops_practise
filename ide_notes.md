# Git в VS Code и в терминале

## Удобно в VS Code
1. **Просмотр diff.** Клик по изменённому файлу в Source Control открывает сравнение «было/стало» бок о бок, изменения видны сразу, без `git diff`.
2. **Индексация частей файла.** Можно добавить в индекс отдельные строки или блоки (Stage Selected Ranges) мышкой — аналог `git add -p`, но наглядный.
3. **GitLens / blame.** Возле каждой строки видно автора, дату и коммит последнего изменения, а история файла открывается в один клик.

## Удобнее в терминале
- **Interactive rebase, cherry-pick, reflog и работа с несколькими remote.** В терминале доступны все флаги, команды можно повторить и вставить в скрипт, а на сервере по SSH другого интерфейса всё равно нет.
